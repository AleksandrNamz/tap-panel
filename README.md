Плата с 3мя кнопками управляется PCA9555 и 3 светодиодами под управлением PCA9532. Кол-во кнопок варьируется по необходимости.

Подключено к Arduino UNO, и памяти eeprom (24C02), общение между ними по I2C.

При нажатии кнопки, загорается светодиод, память сохраняет состояние. При перезагрузке, состояние загружается из памяти, светодиод загорается.
